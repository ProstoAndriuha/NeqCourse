📖 Despre Curs

Devino expert în Data Science și Machine Learning! Acest curs avansat te va învăța să lucrezi cu date complexe, să construiești modele predictive și să implementezi algoritmi de machine learning în proiecte reale.

Vei învăța Python pentru data science, biblioteci esențiale (pandas, NumPy, scikit-learn, TensorFlow), statistică aplicată, vizualizarea datelor și multe altele. Cursul include 20+ proiecte practice cu date reale din industrie.

🎯 Ce vei învăța

  • ✅ Python pentru Data Science: NumPy, pandas, Matplotlib
  • ✅ Analiza exploratorie a datelor (EDA)
  • ✅ Curățarea și preprocesarea datelor
  • ✅ Statistică și probabilități pentru Data Science
  • ✅ Machine Learning: Supervised și Unsupervised Learning
  • ✅ Algoritmi: Regression, Classification, Clustering
  • ✅ Deep Learning cu TensorFlow și Keras
  • ✅ Neural Networks și CNN
  • ✅ Natural Language Processing (NLP)
  • ✅ Model evaluation, tuning și deployment
  • ✅ Big Data cu Spark
  • ✅ Cloud ML: AWS SageMaker, Google Cloud AI

  5. Decision Trees și Random Forests (60 min)

  8. Feature Engineering (55 min)
  9. Model Evaluation Metrics (50 min)
  10. Proiect: House Price Prediction (120 min)
Modul 4: Deep Learning (4 săptămâni)
  1. Neural Networks Basics (50 min)

  5. Recurrent Neural Networks (RNN) (65 min)

  1. Model Deployment cu Flask (45 min)
