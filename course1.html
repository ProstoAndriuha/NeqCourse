📖 Despre Curs

Devino un dezvoltator web full-stack profesionist! Acest curs comprehensiv te va învăța tot ce ai nevoie pentru a construi aplicații web moderne și scalabile, de la frontend până la backend.

Vei învăța să lucrezi cu tehnologii moderne precum HTML5, CSS3, JavaScript ES6+, React, Node.js, Express, MongoDB și multe altele. La finalul cursului vei avea un portofoliu solid de proiecte reale.

🎯 Ce vei învăța

  • ✅ Fundamentele dezvoltării web: HTML5, CSS3, JavaScript ES6+
  • ✅ Framework-uri moderne: React, Redux, React Router
  • ✅ Dezvoltare backend cu Node.js și Express
  • ✅ Baze de date: MongoDB, MySQL, PostgreSQL
  • ✅ Autentificare și securitate: JWT, OAuth, bcrypt
  • ✅ API-uri RESTful și GraphQL
  • ✅ Deployment și hosting: Heroku, AWS, Docker
  • ✅ Control versiuni cu Git și GitHub
  • ✅ Testing: Jest, Mocha, Chai
  • ✅ Best practices și design patterns

Săptămâna 1-2: Fundamentele Web Development (12 lecții, 3 ore)
  1. Introducere în Dezvoltarea Web (15 min)
  2. HTML5 Fundamentals (30 min)
  3. CSS3 și Flexbox (45 min)
  4. CSS Grid Layout (30 min)
  5. Responsive Design (25 min)

  1. ES6+ Features (40 min)
  2. Arrow Functions și Template Literals (20 min)
  3. Destructuring și Spread Operator (25 min)
  4. Promises și Async/Await (45 min)
  5. Fetch API și AJAX (30 min)

  7. OOP în JavaScript (40 min)
  8. Modules și Import/Export (20 min)
  9. Proiect: Weather App cu API (60 min)

  1. Introducere în React (30 min)
  2. Components și Props (40 min)
  3. State și Lifecycle (45 min)
  4. React Hooks (useState, useEffect) (50 min)
  5. Context API (35 min)
  6. React Router (40 min)
  7. Redux Fundamentals (45 min)
  8. Redux Toolkit (35 min)
  9. Styling în React (30 min)
  10. Proiect: E-commerce Frontend (90 min)
Săptămâna 8-10: Backend Development cu Node.js (18 lecții, 5 ore)
  1. Introducere în Node.js (25 min)
  2. Express.js Basics (40 min)
  3. Routing și Middleware (35 min)
  4. RESTful API Design (45 min)
  5. MongoDB și Mongoose (50 min)
  6. CRUD Operations (40 min)
  7. Autentificare cu JWT (55 min)
  8. File Upload (30 min)
  9. Error Handling (25 min)
  10. Proiect: Blog API Complete (80 min)
Săptămâna 11-12: Full-Stack Integration și Deployment (16 lecții, 4 ore)
  1. Conectarea Frontend cu Backend (40 min)
  2. State Management în Full-Stack Apps (35 min)
  3. Git și GitHub Workflow (30 min)
  4. Testing cu Jest (40 min)
  5. Docker Basics (35 min)
  6. Deployment pe Heroku (30 min)
  7. AWS și Cloud Services (40 min)
  8. Security Best Practices (35 min)
  9. Performance Optimization (30 min)
  10. Proiect Final: Full-Stack Social Media App (120 min)
